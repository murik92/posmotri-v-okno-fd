# Посмотри в окно

Проектная работа второго спринта курса «Фулстек-разработчик» Яндекс Практикума.

Веб-приложение для просмотра видео из разных городов. Пользователь может искать видео по названию города и времени суток.

## Технологии

- HTML
- CSS
- Flexbox
